# 共有によるタスク追加

**共有によるタスク追加**: `app/src/main/java/com/toshi0907/oboetotte/share/ShareReceiverActivity.kt`が実体です。`AndroidManifest.xml`で`ACTION_SEND`/`ACTION_SEND_MULTIPLE`(いずれも`mimeType="*/*"`で写真に限らず任意のファイル形式を受け付ける)のintent-filterを持つ`exported="true"`のActivityとして登録しており、他のアプリの共有メニューにOboetotteが表示されます。確認・編集画面は挟まず、起動直後に`taskDao.insert`で「タスク(`yyyy/MM/dd HH:mm`形式のローカル日時)」という名前・デフォルト期限(`TaskViewModel.DEFAULT_DUE_DELAY_MILLIS`、登録時刻の1時間後。他のタスク登録と共有するため`private`から公開に変更)の新規タスクを即座に作成し`ReminderScheduler.schedule`を呼びます。`Intent.EXTRA_STREAM`から取得した共有ファイルの`Uri`(`ACTION_SEND`は単一、`ACTION_SEND_MULTIPLE`は複数)は、複数あってもすべて同じ1件の新規タスクへの添付ファイルとして`AttachmentStorage.copyToStorage`(既存の添付ファイル追加と同じ経路)で端末内にコピーし`taskAttachmentDao.insert`で保存します。`Intent.EXTRA_TEXT`から取得した共有テキストは、trim後の文字列全体が`android.util.Patterns.WEB_URL`に完全一致すればURL共有とみなし`normalizeUrl()`(`MainActivity.kt`内、他のタスク登録〈`EditTaskDialog`〉と共有するため`private`から公開に変更)を通してタスクの`url`に、一致しなければテキスト共有とみなしそのまま`memo`に格納します(ファイルと同時に共有された場合も両方保存します)。画面には何も表示せず(`Theme.Oboetotte.SnoozeDialog`の透過テーマを流用)、保存完了後に`Toast`で結果(添付件数・URL/メモの別を含む)を通知して`refreshTaskWidget`を呼んでから`finish()`します。所属リストは指定できないため常に`listId = null`(リスト未登録)になります。
