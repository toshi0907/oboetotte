# 操作ログ

**操作ログ**: `data/OperationLog`(`id`/`timestamp`〈epoch millis、インデックス付き〉/`source`〈操作の経路〉/`action`〈操作の種別。例: 「タスク追加」「設定変更」〉/`detail`〈対象・変更内容を表す表示用の文字列〉)として、ユーザー操作と自動処理の履歴を記録します(`OperationLogDao`、`AppDatabase`バージョン23→24の`MIGRATION_23_24`)。特定のタスクに対する操作では、対象タスクの`attachmentGroupId()`(繰り返しシリーズ全体で共通のID)を`taskGroupId`列(nullable、インデックス付き。バージョン25→26の`MIGRATION_25_26`で追加)に記録します。タスクに紐づかない操作(設定変更等)と、列の追加前に記録されたログは`null`です。いずれも記録時点の内容を文字列でそのまま保持するため、後から対象のタスク等が削除・改名されても記録当時の内容を表示できます。

- **記録処理(`oplog/OperationLogger`)**: `log`(suspend)と、suspend関数から呼べない設定変更のコールバック等向けの`logAsync`(ViewModelのクリア等で途中キャンセルされないよう、プロセス全体の`CoroutineScope`で書き込む)。記録の失敗で本来の操作が失敗しないよう、例外は握りつぶしてログ出力のみ行います。`source`は`OperationLogSource`の定数(アプリ/通知/ウィジェット/共有/自動)。
- **保存期間**: `OperationLogger.RETENTION_MONTHS`(1ヶ月、端末のタイムゾーンでのカレンダー月)。`OperationLogDao.insertAndPurge`が記録のたびにそれより古いログを削除し、しばらく操作が無かった場合に備えてアプリ起動時(`MainActivity`の`LaunchedEffect`)にも`purgeExpired`を呼びます。
- **記録箇所**: タスクの完了は`TaskCompletion.complete`(引数`source`。アプリ内・通知の「完了」・通知のみタスクの自動完了。実際に完了へ遷移した場合のみ、繰り返しタスクは次回分の期限も併記)、削除は`TaskDeletion.delete`(引数`source`/`action`。手動削除と`CompletedTaskCleanup`の自動削除)で記録します。タスクの追加・編集・未完了に戻す・サブタスク/添付ファイル/リスト/場所/バイブレーションパターンの追加・変更・削除・各種設定変更は`TaskViewModel`、クラウドバックアップの実行結果は`CloudBackupRunner.run`(引数`source`。手動/定期実行)、スヌーズは`SnoozePickerActivity`、共有からの追加は`ShareReceiverActivity`、ウィジェットの追加時の設定は`TaskWidgetConfigureActivity`、エクスポート/インポート・テスト通知・手動の更新確認・アップデートのインストール開始は`MainActivity`で記録します。タスク編集は`oplog/describeTaskChanges`が変更前後の`Task`を比較し、「項目: 変更前 → 変更後」の形式で変更項目のみを列挙します(長いタイトル・URL・メモは30文字で切り詰め。変更が無い保存は記録しない)。通知の発火そのものは操作ではないため記録せず、通知履歴(`docs/architecture/notification-log.md`)側で扱います。
- **画面**: 設定画面の「操作ログ」セクション(「完了タスク」と「デバッグ」の間)の「操作ログ」ボタンから、全画面の`OperationLogScreen`(`MainScreen.OperationLog`)へ遷移します。`TaskViewModel.operationLogs`を新しい順に表示し、「ログを消去」(確認ダイアログあり)で全件削除できます(消去した操作自体を1件記録する)。戻ると設定画面に戻ります。
- **タスクごとの表示**: `TaskDetailDialog`(タスクの詳細画面)の最下部に「操作ログ(N件)」の見出しを置き、タップで展開/折りたたみします(初期状態は折りたたみ)。`TaskViewModel.operationLogs`を`TaskScreen`経由で受け取り、`taskGroupId == current.attachmentGroupId()`で絞り込むため、繰り返しタスクは過去の回の操作も含めてシリーズ全体のログを表示します。サブタスクへの操作はそのサブタスク自身の詳細にのみ表示し(「サブタスク追加」は親タスクへの操作として親に表示)、`taskGroupId`を持たない既存ログは表示しません。`taskGroupId`を記録するのは、タスク追加(アプリ・共有)・編集・完了・未完了に戻す・削除・スヌーズ・添付ファイルの追加/削除・サブタスク追加です。行の描画は`OperationLogScreen`と共通の`OperationLogRow`を使います。
- **バックアップ**: エクスポート/インポートの対象には含めていません(実行時の履歴であり、復元して意味のあるデータではないため)。
