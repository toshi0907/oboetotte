# タスク一覧画面(TaskScreen)

`MainActivity.kt`の`TaskScreen`が一覧UIです(表示は`tasks`、ツリー描画や確認・編集ダイアログへの受け渡しには`allTasks`を使います)。上部は「リスト」ラベル付きの`FilterChip`行(すべて/リスト未登録〈`listId == null`のタスクのみ表示。フィルタ専用の値で`TaskViewModel.UNASSIGNED_LIST_ID`〈`-1L`。Roomの`TaskList.id`は`autoGenerate`で1から始まるため実在のリストIDと衝突しない〉を`selectedListId`にセットして表す〉+各リスト)でリストを切り替える行、その下の「フィルタ」ラベル付きの`FilterChip`行(表示フィルタ。詳細は後述)、さらにその下のもう1つの行(「完了済みを表示」`FilterChip`〈選択状態=`showCompleted`〉、「設定」`AssistChip`)の3段に分かれており、リスト選択・表示フィルタ・それ以外の操作が視覚的に区別されています。

**表示フィルタ**: 「フィルタ」行には`TaskDisplayFilter`(`TaskViewModel.kt`で定義)の各値に対応する`FilterChip`を並べており、現状は「リンクを含む」(`HAS_URL`。`task.url`が空でない)と「今日期限・期限切れ」(`DUE_TODAY_OR_OVERDUE`。後述の`Task.isOverdue`/`Task.isDueToday`のいずれかがtrue。いずれも未完了のタスクのみが対象で、`showCompleted`で完了済みタスクを表示していてもこのフィルタには合致しません)の2種類です。複数選択可能で、選択中の条件はOR判定(いずれか1つでも合致すれば表示)。選択状態は`TaskViewModel.activeDisplayFilters`(`StateFlow<Set<TaskDisplayFilter>>`)で保持し`toggleDisplayFilter`で切り替えます。フィルタは`selectedListId`/`showCompleted`と同じくトップレベルのタスク(`tasks`)にのみ適用し(`TaskScreen`内で`displayedTasks`として算出し`LazyColumn`にはこちらを渡す)、合致した場合はそのサブタスクツリーごと表示します(サブタスク単体が条件に合致しても、親が合致しなければ表示されません)。「今日期限・期限切れ」の判定は1分おきに更新される`nowMillis`(後述)を基準にするため、一覧を開いたままでも日付・時刻をまたぐと自動的に反映されます。**タスク行タップ時の挙動**: 一覧の行をタップすると、まず読み取り専用の確認ダイアログ`TaskDetailDialog`が開きます(直接`EditTaskDialog`は開きません)。`TaskDetailDialog`は`EditTaskDialog`と同じ項目(タイトル・所属リスト・URL・期限・繰り返しルール・位置情報・メモ・添付ファイル・サブタスク一覧)をすべて表示しますが、上部の「編集」ボタンを押すまでは値を書き換える操作(添付ファイルの追加・削除、サブタスクの追加を含む)は行えません。チェックボックスによる完了/未完了の切り替えと、添付ファイルをタップして外部アプリで開く操作だけは確認ダイアログ上でも直接行えます。「編集」ボタンを押すと、その場に(確認ダイアログの上に重ねて)`EditTaskDialog`が開き、タイトル・所属リスト(`FilterChip`で「なし」+各リストから選択。メイン画面の「リスト」フィルタとは独立で、ここでの選択がそのままタスクの`listId`を書き換えます)・期限・繰り返しルール(`FilterChip`で「なし/毎日/毎週/毎月」を選択)に加えてサブタスクの一覧(チェック可能)と追加フォームを編集できます。`EditTaskDialog`自体の内容・保存挙動は本機能追加前から変更していません。
