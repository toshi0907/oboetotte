# 永続化層(Room)

永続化層は`app/src/main/java/com/toshi0907/oboetotte/data/`に置いています(`Task`/`TaskList`/`SavedLocation`/`TaskAttachment`エンティティ、`TaskDao`/`TaskListDao`/`SavedLocationDao`/`TaskAttachmentDao`、`AppDatabase`)。`Task`は`id`/`title`/`isDone`/`dueAt`(epoch millis、任意)/`listId`(`TaskList`への外部キー、任意)/`parentTaskId`(サブタスク用の自己参照、任意)/`repeatRule`(繰り返しルール、任意)/`repeatDaysOfWeek`(`repeatRule`が`WEEKLY_DAYS`の場合のみ使う、選択曜日のカンマ区切り文字列、任意)/`locationName`・`latitude`・`longitude`・`radiusMeters`・`notifyOnArrival`・`notifyOnDeparture`(位置情報リマインダー用、任意。詳細は`docs/architecture/location-reminders.md`)/`url`・`memo`(任意。`url`は通知に「リンクを開く」ボタンとして表示、`memo`は`EditTaskDialog`を開くと表示・編集できる自由記述の文字列。詳細は`docs/architecture/task-url-memo.md`)/`seriesId`(繰り返しタスクが完了して次回分が生成される際に引き継がれる、同じ繰り返しシリーズを束ねるID。任意、詳細は`docs/architecture/task-attachments.md`)/`autoSnoozeMinutes`(オートスヌーズの間隔・分、任意。詳細は`docs/architecture/reminder-notifications.md`)/`notifyOnlyMode`(通知のみタスク、既定`false`。詳細は`docs/architecture/reminder-notifications.md`)を持ちます。いずれもRoom上の`@ForeignKey`制約は付けていません。サブタスクも`Task`と同じテーブル・同じエンティティで表現しており、`parentTaskId`の有無でトップレベルタスクかサブタスクかを区別します。`TaskDao.getAll`は`ORDER BY isDone ASC, dueAt IS NULL ASC, dueAt ASC, id DESC`で全件(トップレベル+サブタスク)を取得し、未完了→期限が近い順→期限なしの順に並びます。`AppDatabase.getInstance(context)`でシングルトンのRoomデータベース(`oboetotte.db`)を取得する構成です。
