# 画面構成(MainActivity)

**画面構成**: `MainActivity`はNavigation Compose等のライブラリを使わず、`setContent`内の`var currentScreen by remember { mutableStateOf(MainScreen.Tasks) }`(`MainScreen`は`MainActivity.kt`内のプライベートな`enum class`で`Tasks`/`Settings`の2値)を`when`で分岐させ、`TaskScreen`と`SettingsScreen`のどちらかをメイン画面全体として描画するだけのシンプルな構成です(両画面とも`Scaffold`の同じ`innerPadding`を共有)。`TaskScreen`側はドロワーの「⚙ 設定」の`onOpenSettings`で`currentScreen = MainScreen.Settings`に、`SettingsScreen`側は先頭の「← 戻る」`TextButton`の`onBack`で`currentScreen = MainScreen.Tasks`に戻します。`SettingsScreen`は`BackHandler`(`androidx.activity.compose`)でシステムの「戻る」操作(戻るジェスチャー・戻るボタン)も同じ`onBack`にフックしており、アプリ終了ではなくタスク一覧への復帰として扱われます。

**ドロワー**: `TaskScreen`はタスク入力欄・タスク一覧以外の操作(リスト選択・表示フィルタ・完了済みの表示・カレンダー表示の切り替え・設定画面への遷移)を、Material 3の`ModalNavigationDrawer`(左からスライドするドロワー)にまとめています。画面上部の`TaskScreenHeader`の☰ボタン(アイコン用ライブラリを追加しないよう`IconButton`内に「☰」の`Text`を表示)、または画面左端からのスワイプで開きます。ドロワーの中身は`TaskScreenDrawer`で、上から「リスト」(`RadioButton`による単一選択)・「フィルタ」(`Checkbox`による複数選択)・「表示」(「完了済みを表示」「📅 カレンダー表示」の`Switch`)・「⚙ 設定」の順です。リストを選ぶとドロワーは自動で閉じ、フィルタ・表示の切り替えでは連続操作できるよう開いたままにします。ドロワーが開いている間はシステムの「戻る」操作で(`BackHandler`)まずドロワーを閉じます。ヘッダーには選択中のリスト名と、有効な表示フィルタ(一覧表示時のみ)を表示し、ドロワーを閉じていても絞り込み状態が分かるようにしています。`drawerState`(`rememberDrawerState`)は`TaskScreen`内に置いているため、設定画面から戻ると常に閉じた状態に戻ります。

`TaskScreen`内には別途、一覧表示とカレンダー表示を切り替える`showCalendar`(`rememberSaveable`)があり、カレンダー表示は`MainScreen`の画面遷移ではなく`TaskScreen`の中で一覧部分を`TaskCalendar`に差し替える形で実装しています(詳細は`docs/architecture/calendar-view.md`)。
