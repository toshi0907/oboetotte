# サブタスクのツリー表示

**メイン画面・確認ダイアログ双方でのサブタスクのツリー表示**: メイン画面のタスク一覧(`TaskScreen`内の`LazyColumn`)は、トップレベルタスク(`tasks`)それぞれを起点に`TaskTreeRow`(再帰的なComposable)で描画しており、直接の子だけでなく孫・ひ孫…まで`depth * 20.dp`のインデント付きで一覧に表示されます。各行のタップで`TaskDetailDialog`(確認ダイアログ、前項)を開き、長押しで削除確認ダイアログを開きます(`combinedClickable`はFoundationのExperimental API)。`TaskDetailDialog`内のサブタスク一覧は同様の考え方の`SubtaskTreeRow`(チェックボックスとタイトルのみの簡易版、行タップで`onOpenTask`コールバック経由の`nestedViewTask`状態を介して、そのサブタスク自身の`TaskDetailDialog`が重ねて開く。`EditTaskDialog`内のサブタスク一覧も同じ`SubtaskTreeRow`を使っていますが、こちらは`nestedTask`状態を介して`EditTaskDialog`自身が重ねて開きます)で描画しています。`TaskTreeRow`・`TaskDetailDialog`・`EditTaskDialog`のいずれも`allTasks`をそのままツリー描画・再帰呼び出しに渡し、各ノードは`allTasks.filter { it.parentTaskId == node.id }`で自分の子だけを算出するため、サブタスクの階層数に上限はありません。**期限の色分け**: `TaskTreeRow`は期限行(`formatDueAt`等の文字列)の文字色を、未完了かつ期限切れ(`isOverdue`)なら`MaterialTheme.colorScheme.error`、未完了かつ期限が当日(`isDueToday`。`task.dueAt`と`nowMillis`をそれぞれ`Instant.atZone(ZoneId.systemDefault()).toLocalDate()`で比較)なら緑系(`ui/theme/Color.kt`の`Green80`/`Green40`。ダイナミックカラー〈`dynamicColor = true`時、端末の壁紙に応じて`tertiary`等のテーマ色が変わる〉の影響を受けないよう固定値にしており、`isSystemInDarkTheme()`でダーク/ライトどちらのテーマかに応じて明るい`Green80`/暗い`Green40`を切り替える)、それ以外は`onSurfaceVariant`に出し分けます。`nowMillis`は`TaskScreen`側で`produceState`(1分おきに`delay`+更新を繰り返す無限ループ)により保持し`TaskTreeRow`へ(再帰呼び出しも含め)引数で渡しています。`System.currentTimeMillis()`や`LocalDate.now()`をComposable内で直接呼ぶと値の変化そのものは再コンポーズをトリガーしないため、タスク一覧を開いたまま日付をまたいでも色分けが更新されない問題があり、この`nowMillis`をstateとして持たせることで解消しています。`SubtaskTreeRow`は期限を表示しないため対象外です。
