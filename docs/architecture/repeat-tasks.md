# 繰り返しタスク

**繰り返しタスク**: `repeatRule`は`RepeatRule`(`TaskViewModel.kt`内の`object`)で定義した`"DAILY"`/`"WEEKLY"`/`"WEEKLY_DAYS"`/`"MONTHLY"`のいずれかです。カスタム間隔(2日おき等)は未対応です。`WEEKLY_DAYS`(UI表示「毎週(曜日)」)は、`Task.repeatDaysOfWeek`にISO-8601の曜日番号(月曜=1〜日曜=7)をカンマ区切りで保存し(`RepeatRule.parseDaysOfWeek`/`formatDaysOfWeek`で相互変換)、複数曜日を選択できます。`EditTaskDialog`で「毎週(曜日)」を選択すると月〜日の`Checkbox`が7つ表示され、最低1つ選択しないと(`selectedDays.isEmpty()`)保存ボタンが無効化されます。タスクを完了にする処理は`TaskCompletion.complete(context, task)`(`TaskCompletion.kt`、アプリ内・通知の両方から共通利用)に集約しており、`repeatRule`と`dueAt`が両方設定されていれば(`WEEKLY_DAYS`の場合はさらに`repeatDaysOfWeek`が空でなければ)`nextDueAt()`(同ファイル内のプライベート関数、`java.time`でローカルタイムゾーンの日時を加算)で次回の期限を計算し、同じタイトル/リスト/親/繰り返しルール/曜日設定を持つ未完了の新規タスクを`taskDao.insert`で生成します。`WEEKLY_DAYS`の次回期限は、現在の期限日の翌日から最大7日分を順に調べ、選択された曜日のうち最も近い日(同じ週内も含む)を採用します。`dueAt`が未設定の繰り返しタスクは、完了しても次回分は生成されません。次回分の生成時は`nextTask.seriesId = task.attachmentGroupId()`(`Task.attachmentGroupId()`、`Task.kt`内の拡張関数で`seriesId ?: id`)を設定して引き継ぎます。これにより繰り返しシリーズの全インスタンス(初回・完了済みの過去分・現在未完了の分すべて)が同じ`seriesId`(初回インスタンスのみ`seriesId`が`null`のままなので、その場合は自分自身の`id`)を共有し、添付ファイルの紐付け(`docs/architecture/task-attachments.md`参照)が繰り返しのたびに途切れず連動し続けます。
