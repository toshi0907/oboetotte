# タスクのURL・メモ

**タスクのURL・メモ**: `Task.url`/`Task.memo`はいずれも任意の文字列で、`EditTaskDialog`のタイトル直下(URL)・サブタスク一覧の直前(メモ、複数行の`OutlinedTextField`)で入力・編集できます。`url`はダイアログ保存時に`normalizeUrl()`(`MainActivity.kt`内のプライベート関数)で先頭が`http://`/`https://`でなければ`https://`を補い、空文字ならNULLとして保存します。`url`が設定されている場合、期限日時通知(`ReminderReceiver`)・位置情報通知(`GeofenceReceiver`)の両方に「リンクを開く」という`NotificationCompat.Action`が追加され、タップすると`ReminderScheduler.openUrlPendingIntent(context, taskId, url)`が`Intent.ACTION_VIEW`でブラウザ等を起動します(通知本体のタップは従来どおりアプリを開きます)。このボタンの`PendingIntent`リクエストコードは`taskId.toInt() * 10 + 9`で、「スヌーズ」ボタンの`taskId.toInt() * 10 + 5`(詳細は`docs/architecture/reminder-notifications.md`)と衝突しないオフセットを使っています。`memo`は通知には表示されず、`TaskDetailDialog`(参照)・`EditTaskDialog`(編集)でのみ扱います。`TaskDetailDialog`ではメモを`LinkifiedMemoText`(`MainActivity.kt`)で表示し、本文中の`http://`/`https://`で始まるURL(`MemoLinks.kt`の`findMemoUrlRanges()`で検出。スキーム無しの`www.〜`等は対象外、日本語・全角記号や空白の手前でURLを区切り、末尾の半角句読点と対応の取れない閉じ括弧は除外)を`LinkAnnotation.Clickable`でリンク色+下線にしてタップでブラウザ等を開きます(開けるアプリが無ければトースト表示)。全体を`SelectionContainer`で囲んでいるため長押しで範囲選択・コピーも可能です。`EditTaskDialog`の入力欄はリンク化しません。
