# TaskViewModel

`TaskViewModel`(`AndroidViewModel`)が両DAOをラップし、`allTasks: StateFlow<List<Task>>`(全件、サブタスク含む)、`tasks: StateFlow<List<Task>>`(`allTasks`を`parentTaskId == null`・選択中の`selectedListId`・`showCompleted`〈デフォルト`false`。`false`なら完了済みのトップレベルタスクを除外〉でフィルタした一覧表示用。この完了済みフィルタはトップレベルタスクにのみ適用され、表示中の親の配下のサブタスクは`TaskTreeRow`/`SubtaskTreeRow`側でこれまでどおり全件表示されます)、`lists: StateFlow<List<TaskList>>`を公開しています。表示フィルタ(「リンクを含む」「今日期限・期限切れ」)の選択状態は`activeDisplayFilters: StateFlow<Set<TaskDisplayFilter>>`(`toggleDisplayFilter`で選択/解除をトグル)として`tasks`とは別に公開しており、実際のフィルタ適用(現在時刻`nowMillis`が必要な「今日期限・期限切れ」判定を含む)は`TaskScreen`側で行います。「今日期限・期限切れ」は`Task.isOverdue`/`Task.isDueToday`(いずれも未完了のタスクのみが対象)の判定に基づくため、`showCompleted`で完了済みタスクを表示していても、完了済みタスクはこのフィルタには合致しません。詳細は`docs/architecture/task-list-screen.md`参照。操作系は、タスクの追加(`addTask`、選択中のリストに紐づく。期限〈`dueAt`〉は登録時刻の`DEFAULT_DUE_DELAY_MILLIS`〈1時間〉後をデフォルトで設定し、`ReminderScheduler.schedule`も同時に呼び出す)・完了切り替え(`toggleDone`、サブタスクにも共用。完了にする側の実処理は`TaskCompletion.complete`に委譲し、未完了に戻す側のみ`taskDao.setDone`+`ReminderScheduler.schedule`+`LocationReminderManager.register`をここで直接行う)・タイトル/所属リスト/期限/繰り返しルール/位置情報の更新(`updateTask(task, edits: TaskEdits)`。`TaskEdits`〈`TaskViewModel.kt`内〉は`EditTaskDialog`で編集可能な全項目をまとめたdata classで、編集ダイアログの項目が増えるたびに`updateTask`の引数を増やす代わりにここへフィールドを追加する)・削除(`deleteTask`)・サブタスク追加(`addSubtask(parent, title)`。`addTask`と同様に期限のデフォルト値〈1時間後〉を設定し`ReminderScheduler.schedule`を呼ぶ)、リストの追加/改名/削除(`addList`/`renameList`/`deleteList`。削除時は`TaskDao.clearListId`でそのリストに属するタスクの`listId`をNULLに戻してから削除)、完了済みタスクの表示切り替え(`setShowCompleted`)。`TaskDao.update`は`@Update`によるRoom標準の全カラム更新です。`savedLocations: StateFlow<List<SavedLocation>>`(名称の昇順)も公開しており、`addSavedLocation(name, latitude, longitude, radiusMeters)`/`updateSavedLocation(location, name, radiusMeters)`〈名称・半径のみ変更可、座標はそのまま〉/`deleteSavedLocation(location)`で操作します(詳細は`docs/architecture/saved-locations.md`)。
